# deskman — Hyprland monitor manager

A small single-file GUI (GTK4 / libadwaita, Python) for arranging Hyprland
monitors: layout ordering, resolution, refresh rate, scale — instead of
hand-editing `~/.config/hypr/monitors.lua`.

Written for a 3-display rig (mixed sizes and fractional scales); it works with
any number of outputs Hyprland reports.

## What it does

- **Live canvas of your desk.** Every output is drawn to scale in logical
  pixels, with its name, mode and scale labelled.
- **Monitors can never be pulled apart.** Dragging a panel reorders the row —
  the others slide aside live and positions are always re-derived from screen
  widths. There is no free placement and no gap to get wrong.
- **Resize by dragging a panel's right edge.** It snaps to the nearest
  EDID-reported resolution only; you cannot invent a size a panel doesn't have.
- **Vertical offsets stay editable** (per-monitor stepper) — that's actual desk
  ergonomics: panels of different heights, cursor crossing at a comfortable height.
- **Apply writes the config, reloads Hyprland, and verifies**: it re-reads live
  monitor state and shows a drift dialog if Hyprland silently ignored anything.
  It never claims success it hasn't checked.
- Offline/disconnected outputs keep their saved rules, so plugging a panel back
  in restores the desk layout instead of auto-panicking.

## Files it owns

| Path | Role |
|---|---|
| `~/.config/hypr/monitors.lua` | generated by deskman (header says so); your hand-written original is frozen to `monitors.lua.pre-deskman` on first takeover |
| `~/.config/deskman/state.json` | deskman's own layout state (kept for offline outputs) |

## Requirements

- Hyprland with the Lua config API (`hl.monitor`, `hl.env`) — Omarchy's layout
  is what it was written against.
- GTK4 + libadwaita + pygobject (`python3-gobject`, `gtk4`, `libadwaita` on Arch).
  No other dependencies.

## Run

```sh
./deskman.py        # or symlink into ~/.local/bin and launch "deskman"
```

## Notes

- `relaunch.sh` is a dev helper (kill + relaunch + grim screenshot over SSH),
  not part of the app.
- `--debug-tree` dumps the widget tree and exits — handy for GUI-over-SSH
  debugging when a window renders empty.
